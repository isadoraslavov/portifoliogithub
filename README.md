# Portfólio Acadêmico

Projeto desenvolvido para a disciplina de versionamento utilizando GitHub e GitHub Pages.

## Objetivo
Criar um portfólio acadêmico profissional para apresentação de projetos, habilidades e contatos.

## Tecnologias utilizadas
- HTML
- CSS
- GitHub
- GitHub Pages

## Projetos apresentados

### Planner Ademicon
Sistema de agenda digital com frontend moderno, backend integrado e autenticação utilizando Supabase.

### Calculadora em Assembly
Projeto acadêmico desenvolvido utilizando linguagem Assembly.

### Portfólio Pessoal
Página desenvolvida para apresentação profissional e organização de projetos acadêmicos.
